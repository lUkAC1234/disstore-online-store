# Router Component

This component is responsible for routing logic, it is wrapper for whole application to have access for NavLink component to route to needed path and get the needed page.

It is very useful, as it uses History API under hood that enables routing on fly without the need of reload which makes dynamic user experience.

As from scratch creating routing logic is not that easy, React-Router library offers set of useful tools that gives you full power over History API as it manages state of router and components for you.
